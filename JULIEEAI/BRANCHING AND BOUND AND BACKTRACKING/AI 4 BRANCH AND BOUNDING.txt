# N-Queens Problem using Branch and Bound

def print_board(board, n):

    for i in range(n):

        for j in range(n):

            if board[i] == j:
                print("Q", end=" ")

            else:
                print("_", end=" ")

        print()

    print()


# Branch and Bound Function
def solve_nqueen(board, row, n, columns, left_diag, right_diag):

    # If all queens are placed
    if row == n:

        print("Solution Found:\n")

        print_board(board, n)

        return True

    # Try placing queen in every column
    for col in range(n):

        # Check if position is safe
        if columns[col] == 0 and \
           left_diag[row - col + n - 1] == 0 and \
           right_diag[row + col] == 0:

            # Place queen
            board[row] = col

            # Mark column and diagonals as occupied
            columns[col] = 1
            left_diag[row - col + n - 1] = 1
            right_diag[row + col] = 1

            # Recursive call
            if solve_nqueen(board, row + 1, n,
                             columns, left_diag, right_diag):
                return True

            # Backtracking (Bound fails)
            board[row] = -1

            columns[col] = 0
            left_diag[row - col + n - 1] = 0
            right_diag[row + col] = 0

    return False


# MAIN PROGRAM
n = 4

board = [-1] * n

# Arrays for Branch and Bound
columns = [0] * n

right_diag = [0] * (2 * n)

print("Solving", n, "Queens Problem using Branch and Bound...\n")

solve_nqueen(board, 0, n,
             columns, left_diag, right_diag)

📘 THEORY

Branch and Bound is an optimization technique used in Artificial Intelligence and combinatorial problems. It divides the problem into smaller branches and eliminates branches that cannot produce valid solutions using bounds.

In the N-Queens problem, queens must be placed such that:

No two queens are in same row
No two queens are in same column
No two queens are on same diagonal

Branching means trying different positions for queens. Bounding means rejecting unsafe positions immediately without exploring them further.

This method is faster than simple backtracking because invalid states are eliminated early using column and diagonal arrays.

✅ CONCLUSION

The N-Queens problem was successfully solved using the Branch and Bound technique in Python. The algorithm efficiently reduced unnecessary computations by checking column and diagonal constraints before recursive calls.
