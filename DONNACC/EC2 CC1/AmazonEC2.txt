AWS EC2 Instance Setup with Apache Web Server
Practical Steps
1. Sign in to AWS Console
Open AWS Management Console.
Login with your AWS account.
2. Open EC2 Service
Search for EC2 in the AWS search bar.
Click on EC2 Dashboard.
3. Launch a New Instance
Click Launch Instance.
Fill the following details:
Name: myEC2server
AMI (Operating System): Ubuntu Server 24.04
Instance Type: t3.micro
4. Create Key Pair
Click Create new key pair.
Enter:
Key Pair Name: mykey
Key Pair Type: RSA
Private Key Format: .pem
Download and save the .pem file safely.
5. Configure Security Group
Allow these rules:
Type
Port
Source
SSH
22
Anywhere
HTTP
80
Anywhere
Then click:
Launch Instance
Connect to EC2 Instance
6. Open Instance
Go to Instances
Select your instance
Click Connect
Choose EC2 Instance Connect
Click Connect
Commands to Run in Terminal
7. Update Packages
Bash
sudo apt update
8. Install Apache Web Server
Bash
sudo apt install apache2 -y
9. Start Apache Service
Bash
sudo systemctl start apache2
10. Enable Apache Service
Bash
sudo systemctl enable apache2
11. Go to Web Directory
Bash
cd /var/www/html
12. Create/Edit HTML File
Bash
sudo nano index.html
13. Write HTML Code
Example:
HTML
<html>
<head>
<title>My AWS Server</title>
</head>

<body>
<h1>Welcome to My EC2 Server</h1>
</body>
</html>
Save the file:
Press CTRL + O
Press Enter
Press CTRL + X
View Website
14. Copy Public IPv4 Address
Go back to EC2 Instances
Copy Public IPv4 Address
Example:
Plain text
http://your-public-ip
Paste it into browser.s


AIM

To create and configure an Amazon EC2 instance and host a web application using Apache Web Server on Ubuntu Linux.

🎯 OBJECTIVE
To understand the working of Amazon EC2 service
To launch and configure an EC2 virtual machine
To learn key pair and security group configuration
To install and configure Apache Web Server on Ubuntu
To host and access a simple HTML webpage using public IP address
📘 THEORY

Amazon EC2 (Elastic Compute Cloud) is a cloud computing service provided by Amazon Web Services (AWS)
 that allows users to create and manage virtual servers in the cloud. It provides scalable computing resources on demand and is part of the Infrastructure as a Service (IaaS) cloud model.

In this practical, an Ubuntu EC2 instance was launched using the AWS Management Console. A key pair was created for secure access, and security groups were configured to allow SSH and HTTP traffic.

Apache Web Server was installed on the EC2 instance using Linux commands. A simple HTML webpage was created and stored in the /var/www/html directory. The hosted webpage was accessed through the public IPv4 address of the EC2 instance using a web browser.

This practical demonstrates cloud server deployment, web hosting, and Linux server configuration.

✅ CONCLUSION

The Amazon EC2 instance was successfully launched and configured on AWS. Apache Web Server was installed on Ubuntu Linux, and a simple HTML webpage was hosted successfully. The webpage was accessed through the public IP address of the EC2 instance, demonstrating practical implementation of cloud-based web hosting using AWS EC2.

“The practical demonstrated successful deployment of a web application on an AWS EC2 instance using Apache Web Server, providing hands-on experience in cloud computing and web hosting.”
