APEX FOR SELECTION SORT

FILE NAME : SelectionSortExample

public class SelectionSortExample {

    // Method for Selection Sort
    public static void selectionSort() {

        // Array of numbers
        Integer[] arr = new Integer[]{64, 25, 12, 22, 11};

        Integer n = arr.size();

        // Selection Sort Logic
        for(Integer i = 0; i < n - 1; i++) {

            Integer minIndex = i;

            for(Integer j = i + 1; j < n; j++) {

                if(arr[j] < arr[minIndex]) {
                    minIndex = j;
                }
            }

            // Swap elements
            Integer temp = arr[minIndex];
            arr[minIndex] = arr[i];
            arr[i] = temp;
        }

        // Print sorted array
        System.debug('Sorted Array: ' + arr);
    }
}

🧠 Important Viva One-Liners

Selection Sort → Finds minimum element and places it correctly
Time Complexity → O(n²)
In-place sorting algorithm → Uses same array for sorting
Swapping → Exchanges positions of elements
Apex syntax → Similar to Java
