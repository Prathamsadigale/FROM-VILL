Installation and Configure Google App Engine (Sorting of Numbers)
STEP 1 — Update Ubuntu
sudo apt update
STEP 2 — Install Python
sudo apt install python3 python3-pip -y
STEP 3 — Install Google Cloud SDK (App Engine Tools)
echo "deb [signed-by=/usr/share/keyrings/cloud.google.gpg] https://packages.cloud.google.com/apt cloud-sdk main" | sudo tee -a /etc/apt/sources.list.d/google-cloud-sdk.list

sudo apt install apt-transport-https ca-certificates gnupg curl -y

curl https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo gpg --dearmor -o /usr/share/keyrings/cloud.google.gpg

sudo apt update

sudo apt install google-cloud-cli -y
STEP 4 — Verify Installation
gcloud --version
STEP 5 — Initialize SDK
gcloud init
STEP 6 — Create Sorting Application
mkdir SortingApp
cd SortingApp
nano main.py
main.py Code
from flask import Flask, request

app = Flask(__name__)

@app.route('/', methods=['GET', 'POST'])
def home():
    result = ""

    if request.method == 'POST':
        numbers = request.form['numbers']
        num_list = list(map(int, numbers.split()))

        sorted_numbers = sorted(num_list)

        result = f"Sorted Numbers: {sorted_numbers}"

    return f'''
    <h1>Sorting of Numbers</h1>

    <form method="post">
        Enter numbers separated by space:
        <input type="text" name="numbers">
        <input type="submit" value="Sort">
    </form>

    <h2>{result}</h2>
    '''

if __name__ == '__main__':
    app.run(debug=True)

STEP 7 — Install Flask
pip3 install flask
STEP 8 — Run Application
python3 main.py

Open browser:
http://localhost:5000
Output Example
Input:
8 2 5 1 9

Output:
[1, 2, 5, 8, 9]
